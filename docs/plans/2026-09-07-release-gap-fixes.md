# A/B/C 审计问题修复计划

**目标：** 修复结算优惠券、权限绕过、二维码跨版本缓存，并保存可追溯代码版本。

**架构：** 延续微信小程序、Vue 后台及 CloudBase 云函数。页面以服务端优惠结果为准；推广只允许已激活分销员；后台只接受已绑定或已配置的管理员身份；推广二维码按小程序版本隔离。

**技术：** JavaScript、wx-server-sdk、Vue 3、Node 本地模拟测试。

## 执行顺序

1. 在 `scripts/page-load-logic-test.js` 增加结算页契约测试，在新的 `scripts/release-gap-test.js` 覆盖后台无账号扫码、管理员非分销员推广和二维码版本切换；先验证当前失败。
2. 修复 `miniprogram/pages/checkout/checkout.js` 的金额参数、券名、不可用券过滤、过期响应和已选券刷新；收紧 `cloudfunctions/coupon/index.js` 的可用券条件。
3. 移除 `cloudfunctions/promotion/index.js` 的管理员冒充分销员逻辑及 `cloudfunctions/adminQrAuth/index.js` 的首次扫码自动店主逻辑，保留已绑定账号和指定旧管理员迁移。
4. 推广二维码缓存和云存储路径记录 `envVersion`，旧无版本缓存重新生成；测试同版本复用及 trial/release 切换。
5. 恢复 A 端消费者入口隔离，更新页面测试，整理本地开发记录忽略规则和部署说明。
6. 运行 smoke、E2E、页面测试、扫码测试、修复专项测试、云函数语法和 diff 检查。审查待提交文件后做本地提交；不把截图或邀请凭据收入提交。

## 云端验收

本轮本地通过不代表云端代码已更新。需部署 coupon、promotion、adminQrAuth 及上传小程序体验版后，由现有已绑定微信确认登录，验证消费者用券、分销员推广和另一消费者扫码绑定。真实资金支付与退款单独验收。
