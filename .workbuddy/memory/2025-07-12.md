# 2025-07-12 工作日志

## 分类/购物车/我的三页问题修复（代码层面）

### 分类页 — 根因定位与修复
**问题**: 分类页左侧列表为空，显示"暂无分类"，伴随"请求失败"toast
**根因**: `cloudfunctions/category/index.js` 的 `ensureSeed()` catch 分支为空（集合不存在时不写入种子分类），且 `exports.main` 的 switch 块无 try-catch 保护，`list` 查询集合不存在时直接崩溃
**修复**:
1. `ensureSeed()` catch 分支改为写入默认分类（内层加 try-catch 防止二次崩溃）
2. 整个 switch 块包裹 try-catch，即使查询失败也返回 `{ success: true, data: [] }`
3. `list` 和 `products` 查询加 `.catch(() => ({ data: [] }))` 兜底
4. 前端 `category.js` 的 `loadCategories` 改为 `silent: true` 避免双重 toast，失败时设置 `loadError` 显示错误状态+重试按钮

### 购物车页 — 底部栏与 tab bar 重叠
**修复**: `.cart-bottom` 的 `bottom:0` 改为 `calc(env(safe-area-inset-bottom,0))`，移除 `safe-bottom` class，加 box-shadow，`.cart-item:last-of-type` 加 margin-bottom 避让

### 我的页 — 订单角标最多显示 1
**修复**: `order` 云函数 `case 'list'` 加 `.count()` 返回 `total`；`user.js` 的 `loadOrderCounts` 从 `data.length` 改为 `total`

### empty-state 组件 — 图标判断异常
**修复**: `icon.indexOf('/')` 改为 `icon && icon[0] === '/'`（真机兼容）
